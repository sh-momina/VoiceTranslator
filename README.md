# 🌍 AI Voice Translator

A real-time desktop application that enables seamless multilingual conversations by translating live speech between two speakers.

The application captures spoken audio, converts it to text, intelligently refines incomplete speech when necessary, translates it into the target language, generates natural AI speech, and delivers the translated voice in real time.

Designed for online meetings, interviews, customer support, remote collaboration, and multilingual communication.

---

## ✨ Features

* 🎙️ Real-time bidirectional voice translation
* 🌐 Supports conversations between multiple languages
* 🤖 Optional AI-powered speech refinement for incomplete spoken sentences
* 🗣️ Natural-sounding AI voice synthesis
* ⚡ Low-latency translation pipeline
* 💬 Context-aware conversation memory
* 🖥️ Modern desktop interface
* 🔄 Automatic audio routing using virtual audio devices
* 📊 Live status and latency monitoring
* 🧩 Modular architecture for easy maintenance and future expansion

---

## 🖥️ Supported Platforms

The translator can be used with communication platforms that allow custom microphone and speaker selection, including:

* Google Meet
* Zoom
* Microsoft Teams
* Discord
* Skype
* Slack Calls
* WhatsApp Desktop
* Telegram Desktop
* Any desktop application supporting custom audio devices

## ⚙️ Technology Stack

* Python 3.12.7

* Microsoft Edge Text-to-Speech
* CustomTkinter

* SoundDevice
* SoundFile
